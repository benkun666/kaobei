# 拷贝漫画 → 腕上漫画 API（实验版）

这是一个实验性的适配器，尝试把 Venera 的公开「拷贝漫画」源使用的上游接口映射成腕上漫画需要的 `/config`、`/search`、`/album`、`/photo`。

## 重要说明
- 尚未在真实托管环境或手表上验证，不能保证上游接口当前可用。
- 这不是已上线的公网地址。部署成功后，平台才会分配真实网址。
- 上游接口、域名、签名规则可能变化，出现 502 时需要维护。
- 请只访问你有权阅读的内容；不提供登录、付费或访问限制绕过。
- 不要把账号密码或 Cookie 放入代码仓库。

## 手机部署概要
1. 在 GitHub 创建一个新仓库，把本项目文件上传进去。
2. 在支持 Python Web 服务的托管平台导入该仓库（例如 Render）。
3. 安装命令：`pip install -r requirements.txt`
4. 启动命令：`gunicorn app:app --bind 0.0.0.0:$PORT`
5. 部署成功后打开 `https://你的域名/config`，确认返回 JSON 且 `apiUrl` 是真实域名。
6. 测试 `https://你的域名/search/海贼王/1`。如果返回 502，说明上游接口还需要调整，不能把它当作已可用源。
7. 只有测试成功后，才把服务根地址填进腕上漫画。

## 路由
- `GET /config`
- `GET /search/<关键词>/<页码>`
- `GET /album/<漫画ID>`
- `GET /photo/<漫画ID>/chapter/<章节序号>`
